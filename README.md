# 🎓 Análise de Qualidade de Ensino

> Painel de IA para monitorar qualidade do ensino por escola e rede. Cruza IDEB, ENEM, frequência e infraestrutura para identificar fatores de sucesso e priorizar políticas.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/edu-qualidade-ensino/

## 📊 Resultados-chave (KPIs)
**monitor.** Escolas · **identif.** Fatores · **projetado** IDEB · **analisada** Equidade

## 🧠 Tecnologias de IA
ML · Causal Inference · Analytics

## ✨ O que faz
- Análise de IDEB e ENEM
- Fatores de sucesso escolar
- Benchmark entre redes
- Priorização de políticas
- Projeção de indicadores

## 🗄️ Fonte de dados real
[IDEB/INEP + Censo Escolar](https://www.gov.br/inep/pt-br/areas-de-atuacao/pesquisas-estatisticas-e-indicadores/ideb)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com IDEB/INEP + Censo Escolar
2. **Processamento com IA** — ML · Causal Inference · Analytics
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
